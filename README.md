# Prop Tech Website MVP

A responsive front-end prototype for Prop Tech, a property agency platform for buying, selling and renting property.

## Included
- Public home page and navigation
- Buy/Rent search
- Property detail pages
- Sell/List Property enquiry form
- Admin workspace
- Sales Agent workspace
- Property approval workflow UI
- Agent management UI
- Lead/CRM pipeline UI
- Add Property multi-step UI
- Projects, locations, property types, featured content, reports and settings modules
- Responsive mobile layout
- Prop Tech cobalt-blue branding

## Run
Open `index.html` in a browser. No build step or dependencies are required for this prototype.

## Demo workspaces
Click **Login** on the public website, then choose Admin Portal or Sales Agent Portal.

## Production next step
Connect the UI to secure authentication, PostgreSQL, cloud image storage, maps, notifications and CRM integrations. Never use the demo client-side data or browser-only login as production authentication.
